# Übung - Migrationsansätze
1. 
* Cold Turkey bzw. Big Bang-Migrationsansatz<br>
Wie der Name Sagt alles auf einmal.

* Rehosting/ Lift-and-Shift<br>
Anwendungen usw. werden von on Prem in die Cloud gehoben ohne inhaltliche veränderung.

* Retire (Ersetzen der Software mit native Cloud-App)<br>
èberholte dinge werden deaktiviert und entfernt.

* Refactor<br>
Die Anwendung wird optimiert, um Vorteile von PaaS- (Platform-as-a-Service) oder IaaS-Umgebungen (Infrastructure-as-a-Service) maximal zu nutzen.

* Rebuild / Reengineering<br>
Das System wird optimiert ohne die funktionalität zu gefärden.
* Chicken-Little-Migrationsansatz<br>
Kleine schritte vorsichtiges vorgehen.
* Butterfly-Migrationsansatz<br>
Es garantiert einen unterbruchslosen betrieb während der migration da bearbeitete daten in einen Zwischenspeicher geladen werden.
* COREM-Migrationsansatz<br>
Phasenweise migration für sicherheit.
