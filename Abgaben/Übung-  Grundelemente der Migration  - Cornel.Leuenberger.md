# Übung-  Grundelemente der Migration
1. Nennen Sie zwei Gründe, wann man eine Software-Migration machen muss<br>
* Um Sicherheit zu erhalten.
* für Leistungssteigerung
2. Wie ist die Definition für das Wort Migration im Skript?<br>
Migration definiert verschiedenste umstellungsprozesse in Datenverarbeitungssystemen.
3. Der Begriff Software-Migration gehört zum welchem Bereich des Software-Engineering?<br>
Zur Software erhaltung
4. Wie ist die Beziehung zwischen Hard- und Software-Migration?<br>
Das eine kommt meist mit dem anderen.
5. Was sollte niemals mit einer Software-Migration vermischt werden und warum?<br>
Mit funktionsänderungen.    
6. Auf was zielt das Reenginierung bei einer Migration ab?<br>
Auf verbesserung ohne die funktionalität zu beeinträchtigen.
7. Was versteht man unter Reverse Enginieering?<br>
Reverse Engineering ist das Ableiten und Nachdokumentieren von Informationen über ein bestehendes System, um es zu verstehen, weiterzuentwickeln, zu sanieren oder zu migrieren, ohne das System selbst zu veränder
